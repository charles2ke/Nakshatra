# Nakshatra Frontend

React + Vite + TypeScript shopping portal frontend.

## Getting Started

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:5173

## Environment Variables

- `VITE_API_BASE_URL` — Backend API base URL (default: `http://localhost:5000`)

## Running Tests

```bash
npx playwright install --with-deps chromium
npm run test:e2e
```

## Build

```bash
npm run build
```
